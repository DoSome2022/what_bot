2. 前置需求

項目說明
一台機macOS / Linux / Windows(WSL) 皆可；建議 2GB RAM 以上
Node.js版本 ≥ 18（含 npm）
獨立 WhatsApp 號碼給 bot 專用，不要用主力號碼（有被封風險）
AI API Key至少一個（DeepSeek / Kimi / OpenAI / Gemini / Anthropic 任一）
⚠️ 三個務必記住：
1. 用獨立號碼登入 bot，別用自己的私人號碼。
2. data/auth 資料夾 = 登入憑證，洩漏等於帳號被劫持，要備份好。
3. API Key 是按用量計費的，別外流。

3. 安裝流程

1
安裝 Node.js（已裝可跳過，先確認版本） 
node -v        # 需顯示 v18 或以上
npm -v

macOS 用 Homebrew：brew install node；或到 nodejs.org 下載安裝。

2
取得專案代碼
把 whatsapp-multi-llm-bot 資料夾複製到部署機上，進入： 
cd whatsapp-multi-llm-bot
3
安裝依賴 
npm install

看到 added N packages 即成功。

4
建立設定檔 
cp .env.example .env
然後用文字編輯器打開 .env，照下一節填寫。

4. 設定 .env（欄位對照表）

用編輯器打開 .env，至少填 ADMIN_PHONES 和一個對應的 API Key。

欄位說明範例
ADMIN_PHONES管理員電話（國碼+號碼，逗號分隔），可拉群、用指令85291234567,85298765432
TRIGGER_SYMBOL群組觸發符號（訊息前綴）!
TRIGGER_PASSPHRASE群組觸發暗號（訊息內含此字串即觸發）（留空 = 不用暗號）
LLM_PROVIDER預設模型：deepseek / deepseek-anthropic / kimi / openai / google / anthropickimi
LLM_MODEL指定模型名（留空用預設）（可留空）
DEEPSEEK_API_KEYDeepSeek 金鑰sk-...
DEEPSEEK_ANTHROPIC_TOKENDeepSeek Anthropic 端點 token（同 Claude Code 用的）（可留空，會自動沿用 DEEPSEEK_API_KEY）
KIMI_ANTHROPIC_TOKENKimi（Moonshot）Anthropic 端點 tokensk-...
OPENAI_API_KEYOpenAI 金鑰sk-...
GOOGLE_API_KEYGoogle Gemini 金鑰AIza...
ANTHROPIC_API_KEYClaude 金鑰sk-ant-...
SYSTEM_PROMPT自訂 AI 系統提示詞（留空用預設客服）（可留空）
💡 若用 deepseek-anthropic：DEEPSEEK_ANTHROPIC_TOKEN 與 DEEPSEEK_API_KEY 是同一把 key（sk-c488...），可只填 DEEPSEEK_API_KEY 即可。
若用 kimi：需填 KIMI_ANTHROPIC_TOKEN（對應 start.sh 裡 Kimi 的 ANTHROPIC_AUTH_TOKEN）。

5. 啟動並登入

1
啟動程式 
npm start
終端機會顯示一個 QR Code。
2
掃 QR 登入
用「bot 的獨立號碼」手機，打開 WhatsApp → 設定 → 已連結的裝置（多裝置） → 掃描 QR。
3
確認連線
看到這行代表成功： 
✅ Bot 已連線，號碼: 852xxxxxxxx:xx@s.whatsapp.net
⚠️ QR 碼幾分鐘會過期，過期就重跑 npm start 重新掃。
掃碼後如果幾秒就斷線重連，通常是號碼沒開「多裝置」或用了主力號被 WhatsApp 限制。

6. Docker 部署（可選，推薦長開）

不想一直開著終端機，就用 Docker 背景執行、開機自啟。

cd whatsapp-multi-llm-bot
cp .env.example .env      # 先填好 .env
docker compose up -d --build
docker compose logs -f bot   # 第一次看 QR，掃碼登入

之後日常管理：docker compose logs -f bot 看狀態、docker compose restart bot 重啟。

7. 驗證是否成功

  1. 用管理員號碼私訊 bot 隨便問一句，例如「你好」，應該收到 AI 回覆。
  2. 用管理員號碼打 /help，應該收到指令清單。
  3. 用管理員號碼打 /model kimi，確認可切換到 Kimi。
  4. 把 bot 拉進一個測試群，看到「🤖 已加入」即拉群授權正常。
  5. 在群內打 !測試（前綴符號），應該收到回覆。
  6. 重啟程式後，再問一次「我們剛剛講到哪」，bot 應該還記得（上下文已持久化）。
✅ 以上步驟都過，代表整合成功，可以正式使用。

8. 使用手冊

8.1 角色與權限

身分能做什麼
管理員（老闆/員工）拉群、授權、封鎖、切模型、查名單
受權客人問問題（私訊直接問、群組用暗號）
未受權一概不理

8.2 管理員指令（私訊或群組內打）

指令作用
/help顯示指令說明
/admin 852xxxxxxxx設為管理員
/allow 852xxxxxxxx授權可問問題
/remove 852xxxxxxxx移除授權
/ban 852xxxxxxxx封鎖
/unban 852xxxxxxxx解除封鎖
/model <名稱>切換模型（deepseek / deepseek-anthropic / kimi / openai / google / anthropic）
/list查看受權名單、黑名單、群組
/clear清除當前對話記憶
/leavebot 退出當前群組（群組內用）

8.3 客人怎麼問問題

  • 私訊：受權客人直接問即可。
  • 群組：打前綴符號（預設 !）、或 @提及 bot、或說暗號（若設了）才會回答。

8.4 資料位置（要備份的）

路徑內容
data/auth/登入憑證（session），洩漏=帳號被劫持，備份請加密
data/state.json受權名單 / 黑名單 / 群組 / 管理員
data/history/每個對話的上下文記憶（新增，重啟不丟）

9. 常見問題

症狀原因 / 解法
QR 碼不顯示Node 版本太舊（需 ≥18）；重新 npm install
掃碼後秒斷、一直重連號碼未開「多裝置」；或用了受限號碼。改用獨立號碼重試
AI 回「暫時無法回答」API Key 沒填/填錯，或模型名過時。看終端 log 的錯誤訊息
切到 kimi 後報錯KIMI_ANTHROPIC_TOKEN 未填。填上 start.sh 裡 Kimi 的 token 後重跑
切到 deepseek-anthropic 後報錯確認 DEEPSEEK_API_KEY 已填（會自動沿用）
報 model not found模型名改了，填正確名到 LLM_MODEL
帳號被封換備用號碼，刪 data/auth 後重跑重掃
要換 bot 號碼停掉程式 → 刪 data/auth → 重跑 → 新號碼掃碼
重啟後不記得對話現在已持久化到 data/history/，正常情況重啟仍記得；若仍不記，檢查該資料夾是否有寫入權限
